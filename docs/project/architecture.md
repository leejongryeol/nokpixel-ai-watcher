# 시스템 구조

## 전체 구조

```
┌──────────────────────────┐        ┌──────────────────────────┐        ┌──────────────┐
│  녹픽던 게임 (Java)       │  상태   │  ai-bridge (Python)       │  요청   │  생성형 AI    │
│                          │ ─────▶ │                          │ ─────▶ │  (Claude API) │
│  · 판단 순간 감지          │        │  · 상태를 프롬프트로 정리   │        │              │
│  · 게임 상태 → JSON        │ ◀───── │  · AI 답을 행동으로 변환    │ ◀───── │  행동 + 이유  │
│  · 행동 실행              │  행동   │  · 판단 기록 저장          │  응답   │              │
└──────────────────────────┘        └────────────┬─────────────┘        └──────────────┘
                                                 │ 기록
                                                 ▼
                                    ┌──────────────────────────┐
                                    │  관찰 화면                 │
                                    │  AI 생각 / 게임 화면 / 패널  │
                                    └──────────────────────────┘
```

- **게임 ↔ ai-bridge**: 로컬 통신(예: 소켓 또는 파일). 방식은 7주차에 확정
- **ai-bridge ↔ AI**: Claude API. 웹 검색 도구는 붙이지 않음
- **언어 설정**: 게임 상태는 기호·숫자 위주, AI의 생각은 한국어로 출력

## 녹픽던 코드에서 사용할 지점

| 코드 위치 | 무엇인가 | 용도 |
|---|---|---|
| `Hero.ready` | 게임이 플레이어 입력을 기다리는 상태 | AI 호출 타이밍 |
| `Hero.interrupt()` | 돌발 상황에서 게임이 이동을 멈추는 지점 | 판단 순간 감지 |
| `Hero.checkVisibleMobs()` | 새 적이 시야에 들어왔는지 확인 | 판단 순간 감지 |
| `HeroAction` | 이동, 공격, 줍기, 계단 이동 등 행동 목록 | AI에게 줄 선택지 |
| `Level.map`, `width`, `height` | 맵 지형 (한 줄 배열, `칸 번호 = x + y × width`) | 문자 지도 생성 |
| `Level.visited`, `mapped`, `heroFOV` | 가본 칸, 밝혀진 칸, 지금 보이는 칸 | 플레이어가 아는 칸만 전달 |
| `Mob.state` | 적 상태 (SLEEPING, HUNTING, WANDERING 등) | 적 정보 |
| `Char.HP`, `HT`, `Hunger` | 체력, 최대 체력, 배고픔 | 상태 정보 |
| `Belongings`, `Item.isIdentified()` | 소지품, 감정 여부 | 가방 정보 |
| `GLog` | 게임 메시지 로그 | 상황 설명 보조 |
| `Hero.die(cause)`, `Statistics` | 사망 원인, 도달 층 등 통계 | 관찰 리포트 |
| `Dungeon.seed` | 맵 생성 시드 | 같은 던전 재현 (AI에게는 숨김) |

## AI에게 보내는 상태 예시

```
[3층] 체력 12/20 | 배고픔: 보통 | 레벨 3
주변 지도 (@=나, #=벽, .=바닥, +=문, >=내려가는 계단, r=쥐, !=물약)
# # # # # # #
# . . r . . #
# . @ . . ! +
# . . . . . #
# # # > # # #
적: 쥐 (오른쪽 위 1칸, 추적 중)
가방: 주황색 물약(미감정) 1개, 빵 1개
최근 메시지: 쥐가 당신을 물었다.
가능한 행동: 이동(좌표), 공격(대상), 아이템 사용(번호), 줍기, 대기
```
