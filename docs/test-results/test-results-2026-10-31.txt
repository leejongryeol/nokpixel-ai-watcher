5. 던전 1층 생각만 모드 3번 (--dry-run --steps 3)
==================================================
명령: python mvp.py --dry-run --steps 3 --model gpt-6-luna --player portrait3
사용자가 게임(540×960)을 켜고 던전 1층에 들어간 뒤 실행

[실패] run_20261031_151849_portrait3
  - 판단 1번 뒤 UnicodeEncodeError: 'cp949' codec can't encode character '\U0001f9e0'
  - 원인: 출력을 다른 명령(tail)으로 넘기면 Windows 기본 인코딩(cp949)으로 이모지를 출력하지 못함
          (mvp.py의 출력 부분, 이번 수정과는 관계없음)
  - API는 1번 호출됨 (약 $0.0002)
[성공] run_20261031_151906_portrait3 (PYTHONIOENCODING=utf-8 로 다시 실행)
  - config.json: display "1080", game_window [540, 960], ai_image [360, 640]
  - step_001~003.png 모두 360×640
  - 던전 1층 시야: 가로 약 11칸, 세로 약 20칸 (계산한 180×320 영역과 맞음)
  - 비용: 약 $0.001 (토큰 입력 1583 / 1679 / 1750, 출력 160 / 129 / 138)

AI가 화면을 맞게 읽었는지 (step_001.png와 판단 1의 생각 비교)
  - 맞음: 캐릭터가 방의 북서쪽에 있음
  - 맞음: 남쪽에 물길과 가운데를 가로지르는 나무 다리
  - 틀림: "오른쪽 아래에 출구처럼 보이는 계단" → 계단은 캐릭터 바로 오른쪽(같은 방)에 있는 올라가는 계단,
          오른쪽 아래에 있는 것은 문
  - 생각만 모드라 캐릭터가 움직이지 않았고, 3번 모두 "남쪽으로 이동"을 고름
  - 큰 지형은 읽었지만 작은 물건(계단 아이콘)의 정체·위치는 틀림. 사진 크기 탓인지 모델 한계인지는
    3번만으로는 알 수 없음
