# 판단 순간과 숨길 정보

녹픽던 v4.0.0 소스 코드를 조사해 정리한 표입니다.

## A그룹: 돌발 상황 대처 판단
> AI에게 **지금 당장** 어떻게 대처할지 판단을 요구하는 부분. 대부분 게임이 `Hero.interrupt()`를 부르는 지점

| 상황 | AI에게 묻는 질문 | 코드 위치 | 등장 |
|---|---|---|---|
| 새 적이 시야에 들어옴 | 싸울까, 피할까, 기습할까? | `Hero.checkVisibleMobs()` | 1~5층 |
| 공격받음 | 반격할까, 물러날까? | `Hero.damage()`, `Char.java` | 1~5층 |
| 큰 피해를 입음 | 도망칠까, 물약을 마실까? | `Hero.damage()` | 1~5층 |
| 굶어 죽기 직전 | 음식을 먹을까, 아껴둘까? | `Hunger.java` (`STARVING`) | 1~5층 |
| 함정을 밟음 | 어떻게 수습할까? | `Level.java` | 1~5층 |
| 식물을 밟음 | 효과에 어떻게 대응할까? | `Plant.trigger()` | 1~5층 |
| 숨겨진 무언가 발견 | 조사할까, 지나칠까? | `Hero.java` (탐색) | 1~5층 |
| 낭떠러지 앞 | 뛰어내릴까? | `Chasm.java` | 1~5층 |
| 마비·어지러움 걸림 | 풀린 뒤 어떻게 할까? | `Hero.add(buff)` | 1~5층 |
| 순간이동 당함 | 낯선 위치에서 어디로 갈까? | `ScrollOfTeleportation` | 1~5층 |
| 거미줄·사슬·소환 등 적 특수행동 | 어떻게 대응할까? | `Spinner`, `Guard`, `Necromancer` | 6층 이후 |
| 보스 특수 공격 | 어떻게 버틸까? | `DM300` 등 | 보스층 |

## B그룹: 전략적 계획 판단
> AI에게 **앞으로의 계획**을 묻는 부분. 대부분 `windows/` 폴더의 선택 창

| 상황 | AI에게 묻는 질문 | 코드 위치 | 등장 |
|---|---|---|---|
| 유령 퀘스트 보상 | 무기와 갑옷 중 무엇을 받을까? | `WndSadGhost` | 1~5층 |
| 레벨업 특성 선택 | 어떤 능력을 키울까? | `Hero.talentPointsAvailable()` | 1~5층 |
| 아이템 강화 | 무엇을 강화할까? | `WndUpgrade` | 1~5층 |
| 앵크 부활 | 부활하며 무엇을 챙길까? | `WndResurrect` | 앵크 소지 시 |
| 상점 거래 | 무엇을 사고팔까? | `WndTradeItem` | 6층 이후 |
| 지팡이 장인·대장장이 보상 | 어떤 보상을 받을까? | `WndWandmaker`, `WndBlacksmith` | 6층 이후 |
| 전직 선택 | 어떤 전문 직업으로 갈까? | `WndChooseSubclass` | 2구역 보스 이후 |
| 특수 능력 선택 | 어떤 능력을 고를까? | `WndChooseAbility` | 후반 |
| 각종 확인 창 | 정말 이 행동을 할까? | `WndOptions` | 전 구간 |

**5층 목표 기준 관찰 가능**: A그룹 10개, B그룹 3~4개

## C그룹: AI에게 숨겨야 할 정보
> 플레이어가 **화면에서 알 수 없는 정보**. 넘기면 치트가 되고, "불확실한 정보 속 판단"이라는 탐구가 무너진다

| 숨길 정보 | 왜 숨겨야 하나 | 코드 위치 | 대신 넘길 것 |
|---|---|---|---|
| 맵 전체 구조 | 안 가본 곳까지 다 보임 | `Level.map` | `visited`·`mapped`·`heroFOV`로 본 칸만 |
| 층 전체 몬스터 목록·수 | 숨은 적 위치까지 다 보임 | `Level.mobs` | 시야 안(`heroFOV`)의 적만 |
| 바닥 아이템 전체 목록·수 | 어디에 뭐가 있는지 다 보임 | `Level.heaps` | 시야 안 또는 본 적 있는 아이템만 |
| 계단 위치 | 탐색 없이 바로 직행 가능 | `Level.exit`, `transitions` | 발견한 계단만 |
| 숨겨진 문 | 찾아야 보이는 통로가 드러남 | `Terrain.SECRET_DOOR` | 발견 전엔 벽으로 표시 |
| 숨겨진 함정 | 밟기 전 위험을 미리 앎 | `Terrain.SECRET_TRAP`, `Trap.visible` | 발견 전엔 바닥으로 표시 |
| 미감정 물약·주문서의 진짜 정체 ⭐ | 불확실한 정보가 사라짐 | `Potion.isKnown()`, 아이템 클래스 이름 | "주황색 물약"처럼 겉모습만 |
| 장비의 저주 여부 | 착용 전 위험을 미리 앎 | `Item.cursed`, `cursedKnown` | 확인 전엔 "저주 여부 모름" |
| 장비의 강화 수치 | 성능을 미리 앎 | `Item.levelKnown`, `buffedLvl()` | 확인 전엔 "수치 모름" |
| 상자로 위장한 미믹 | 함정 몬스터가 드러남 | `Mimic`, `GoldenMimic` 등 | 정체 드러나기 전엔 상자로 |
| 몬스터 드롭 아이템 | 잡으면 뭘 주는지 미리 앎 | `Mob.loot`, `lootChance()` | 넘기지 않음 |
| 맵 생성 시드 | 다음 층을 예측할 여지 | `Dungeon.seed` | 넘기지 않음 (실험 기록용으로만) |

> ⚠️ **가장 흔한 실수**: 미감정 물약도 내부적으로는 `PotionOfHealing` 같은 진짜 이름의 클래스예요. 아이템 이름을 뽑을 때 클래스 이름을 쓰면 AI가 정답을 알게 됩니다. 반드시 **게임 화면에 표시되는 이름**을 쓸 것.

**원칙**: 플레이어 화면에 보이는 것만 AI에게 보여준다.
