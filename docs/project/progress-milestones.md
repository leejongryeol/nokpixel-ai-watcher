# 진행도 이정표 (평가용)

> 상태: 설계 (10/14). **A-6-2(11/4)부터 게임 데이터로 자동 기록**한다 (`logs/<판>/milestones.json`, 리포트의 "진행도 이정표"). 기준은 아래 "자동 기록 기준". 게임 데이터를 받기 전의 판(11/2까지)은 "이정표 기록 없음". 점수는 실험해 보며 조정할 수 있다.

## 왜 필요한가

최종 결과를 "보스 처치 O/X + 도달 층"으로만 남기면, 대부분의 판이 "보스 못 잡음, 2~3층"으로 비슷하게 기록된다.
그러면 공략 O/X, 교훈 이어받기, 모델별 차이가 잘 드러나지 않는다.

OpenAI VPT 논문(2022)은 다이아몬드 곡괭이까지 가는 길을 단계로 쪼개고, 뒤 단계일수록 점수를 높게 줬다
(나무·돌 1점 → 석탄 2점 → 철 4점 → 다이아 8점, 많이 모으는 아이템은 개수로 나눔. 논문 부록 G.1, 표 7).
이 프로젝트는 AI를 **학습시키지 않으므로** 이 점수를 보상이 아니라 **평가 지표**로만 쓴다.
AI에게는 점수를 알려주지 않는다. AI가 받는 목표는 여전히 "5층 보스 처치" 하나다.

## 이정표 표

| 단계 | 이정표 | 점수 | 기록 방법 (A-6-2부터 자동) |
|---|---|---|---|
| 1단계 · 적응 (1점) | 첫 적 처치 | 1 | `Statistics.enemiesSlain` |
| | 첫 아이템 줍기 | 1 | 가방 아이템 수 변화 |
| | 2층 도착 | 1 | `Dungeon.depth`, `Statistics.deepestFloor` |
| 2단계 · 성장 (2점) | 3층 도착 | 2 | `Statistics.deepestFloor` |
| | 캐릭터 레벨 3 달성 | 2 | `Hero.lvl` |
| | 장비 강화 (더 좋은 무기·갑옷 착용, 강화 주문서 사용) | 2 | `Belongings` 변화 |
| | 미감정 아이템을 써서 정체 확인 | 2 | `Item.isIdentified()` 변화 |
| 3단계 · 준비 (4점) | 4층 도착 | 4 | `Statistics.deepestFloor` |
| | 5층 도착 | 4 | `Statistics.deepestFloor` |
| 4단계 · 보스 (8점) | 보스 "구"와 전투 시작 | 8 | 보스 시야 진입 |
| | 구 체력 절반 이하 | 8 | 보스 `HP / HT` |
| 최종 (16점) | **구 처치** | 16 | 보스 사망 |

- 같은 이정표는 한 판에 한 번만 점수를 준다 (VPT의 "개수로 나누기"와 같은 이유: 한 가지에 매달리는 판이 높게 나오지 않게).
- 만점 51점. 리포트에는 점수와 함께 **각 이정표에 도달한 판단 번호**를 남긴다 → "몇 번 판단 만에 3층에 갔나"로 효율도 비교.
- 판이 끝난 이유(사망 원인, 판단 횟수 소진, 중지)를 함께 기록한다. 끝난 이유는 `ended_reason`으로 기록 중. ⬜ 사인 기록 안 됨 (A-6-3에서 넣음)

## 자동 기록 기준 (A-6-2)

게임은 주인공이 입력을 기다리게 될 때마다 상태(⑧)를 보내고, 그 안의 `record` 칸으로 판정한다 ([game-state.md](game-state.md) 6장·9장). `record`와 점수는 **AI 입력에 넣지 않는다.**
처음 맞을 때 `milestones.json`에 `{id, label, points, step, at, depth}` 한 줄. `step`은 그 상태를 받을 때의 판단 번호(그 판단의 행동 결과), 첫 판단 전이면 0.

| 이정표 | 기준 | 비고 |
|---|---|---|
| 첫 적 처치 | `Statistics.enemiesSlain`이 판 첫 상태보다 늘어남 | |
| 첫 아이템 줍기 | 장착+가방 아이템 수량 합이 바로 앞 상태보다 늘어남 | ⬜ 던졌다 다시 주운 것, 상점에서 산 것도 들어간다 (5층까지 상점 없음) |
| 2·3·4·5층 도착 | `Statistics.deepestFloor` ≥ N | 한 번에 여러 층을 내려가면 함께 기록 |
| 캐릭터 레벨 3 | `hero.lvl` ≥ 3 | |
| 장비 강화 | `Statistics.upgradesUsed`가 늘어남, 또는 장착 무기·갑옷 물건이 바뀜 | ⬜ "더 좋은" 장비인지는 판단하지 않는다 |
| 미감정 아이템 정체 확인 | 정체를 아는 물약·주문서·반지 종류 수가 판 첫 상태보다 늘어남 | ⬜ 써서 알았는지 감정 주문서로 알았는지 구분하지 않는다. 종류 수만 보내고 어떤 것인지는 보내지 않는다 |
| 구와 전투 시작 | 5층에서 구가 한 번이라도 시야(`heroFOV`)에 들어옴 | |
| 구 체력 절반 이하 | 본 적 있는 구의 `HP/HT` ≤ 0.5 | |
| 구 처치 | 본 적 있는 구가 죽었거나 층에서 사라짐 | ✅ `Goo.die()` → `GameScene.bossSlain()` |

## 함께 관찰할 것: "속이는 목표"

VPT 논문은 지금 단계에 가장 좋은 행동이 다음 단계를 어렵게 만드는 경우를 "속이는 보상"이라고 불렀다
(돌을 빨리 캐려고 작업대를 두고 가면 돌 곡괭이를 못 만듦). AI가 중간 목표를 스스로 세울 때 같은 함정이 생길 수 있다.

| 녹픽던에서 생길 수 있는 장면 | 리포트에서 보는 법 |
|---|---|
| 숨겨진 길 탐색(e e)에 오래 머물다 배고픔이 쌓임 | 같은 층 판단 수, 배고픔 상태 |
| 지금 체력을 채우려고 미감정 물약을 다 마셔 보스전에 쓸 게 없음 | 물약 사용 시점과 층 |
| 아이템을 모으려고 층을 다 돌다가 위험한 적을 계속 만남 | 층별 판단 수, 받은 피해 |
| 빨리 내려가려고 장비 강화 없이 5층 도착 | 5층 도착 시 레벨·장비 |
