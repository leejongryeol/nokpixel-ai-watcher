# 판단 요청과 숨길 정보

녹픽던 v4.0.2 소스 코드를 조사해 정리한 문서입니다.
AI는 매 턴이 아니라 아래 **판단 요청**이 생겼을 때만 호출됩니다.

## 판단 요청 구조

```
[AI 판단 요청]
 ├─ 기본 ─── Hero.ready() ─── ① 목적 달성   ② 층 이동
 ├─ A그룹 ── Hero.ready() ─── ③ 돌발 상황 (게임이 interrupt()로 하던 일을 끊음)
 └─ B그룹 ── 별도 감지 ────── ④ 선택 창   ⑤ 추가 경고 (게임은 ready()로 알려주지 않음)
```

- **기본·A그룹**: 게임의 `Hero.ready()`(주인공이 다음 명령을 기다리는 상태)가 불리는 순간. `ready()` 한 곳에 신호를 걸고, **왜 멈췄는지(이유)** 를 함께 기록한다.
  - `interrupt()`가 불렸으면 → A그룹 (어떤 돌발인지 함께 기록)
  - 층이 바뀌었으면 → ② 층 이동
  - 그 외 → ① 목적 달성
- **B그룹**: `ready()`가 아닌 순간이라 따로 감지한다. 선택 창이 열릴 때, 또는 상태 값이 기준을 넘을 때.
- AI에게는 판단 요청의 **이유**를 함께 알려준다. ("새 적이 나타나서 멈췄다", "목표 지점에 도착했다" 등)

> ⚠️ **AI의 명령은 목적 단위여야 한다.** "한 칸 이동"처럼 작은 명령을 주면 한 칸마다 `ready()`가 불려 ① 목적 달성이 너무 자주 일어난다. 명령은 "(5,7)까지 이동", "체력이 찰 때까지 휴식", "탐색"처럼 끝이 분명한 단위로 준다.

## 기본 판단 요청 (`Hero.ready()`)

| # | 이유 | 상황 | 코드 위치 |
|---|---|---|---|
| ① | 목적 달성 | 이동 명령 도착 | `Hero.actMove()` → `ready()` |
| ① | 목적 달성 | 휴식 완료 (체력 회복) | `Hero.rest()` → `ready()` |
| ① | 목적 달성 | 탐색 완료 | `Hero.search()` → `ready()` |
| ① | 목적 달성 | 공격·줍기·상자 열기·문 열기·대화 완료 | `Hero.actAttack()`, `actPickUp()`, `actOpenChest()`, `actUnlock()`, `actInteract()` |
| ② | 층 이동 | 계단으로 새 층 도착 / 위층 복귀 | `Hero.actTransition()`, `Dungeon.depth` 변화 |

## A그룹: 돌발 상황 (`interrupt()` → `Hero.ready()`)

> AI에게 **지금 당장** 어떻게 대처할지 판단을 요구한다.

## B그룹: 선택 창과 추가 경고 (별도 감지)

> 게임은 `ready()`로 알려주지 않지만 AI 판단이 필요한 순간. 선택 창은 열릴 때, 경고는 상태 값이 기준을 넘을 때 감지한다.

### ④ 선택 창

| # | 선택 창 | AI에게 묻는 질문 | 코드 위치 | 등장 |
|---|---|---|---|---|
| B1 | 아이템 선택 창 (감정·강화 주문서 등) | 어떤 아이템을 고를까? | `WndBag` | 전 구간 |
| B2 | 아이템 사용 메뉴 | 마실까, 던질까, 버릴까? | `WndUseItem`, `WndInfoItem` | 전 구간 |
| B3 | 확인 창 ("정말 하시겠습니까?") | 정말 할까? | `WndOptions` | 전 구간 |
| B4 | 레벨업 특성 선택 | 어떤 능력을 키울까? | `Hero.talentPointsAvailable()`, `WndHero` | 전 구간 |
| B5 | 유령 퀘스트 보상 | 무기와 갑옷 중 무엇을 받을까? | `WndSadGhost` | 하수도 (2~4층) |
| B6 | NPC 대화 / 퀘스트 안내 | 퀘스트를 받을까? | `WndQuest` | 퀘스트마다 |
| B7 | 앵크 부활 | 무엇을 챙겨 부활할까? | `WndResurrect` | 앵크 소지 시 |
| B8 | 지팡이 장인 보상 | 어떤 지팡이를 받을까? | `WndWandmaker` | 감옥 |
| B9 | 상점 거래 | 무엇을 사고팔까? | `WndTradeItem` | 6층 이후 상점 |
| B10 | 대장장이 보상 | 어떤 보상을 받을까? | `WndBlacksmith` | 동굴 |
| B11 | 드워프 퀘스트 | 퀘스트를 받을까? | `WndImpOld` | 도시 |
| B12 | 전직 선택 | 어떤 전문 직업으로 갈까? | `WndChooseSubclass` | 10층 보스 이후 |
| B13 | 특수 능력 선택 | 어떤 능력을 고를까? | `WndChooseAbility` | 20층 보스 이후 |

**AI 판단 없이 자동으로 닫을 창** (판단 요청 아님)
`WndStory`(구역 이야기), `WndDocument`(모험가 가이드), `WndMessage`·`WndTitledMessage`(안내), `WndSupportPrompt`(후원 안내), `WndBadge`(업적). 가이드·튜토리얼은 설정에서 꺼둔다.

## C그룹: AI에게 숨겨야 할 정보

> 플레이어가 **화면에서 알 수 없는 정보**. 넘기면 치트가 되고, "불확실한 정보 속 판단"이라는 탐구가 무너진다

| 숨길 정보 | 왜 숨겨야 하나 | 코드 위치 | 대신 넘길 것 |
|---|---|---|---|
| 맵 전체 구조 | 안 가본 곳까지 다 보임 | `Level.map` | `visited`·`mapped`·`heroFOV`로 본 칸만 |
| 층 전체 몬스터 목록·수 | 숨은 적 위치까지 다 보임 | `Level.mobs` | 시야 안(`heroFOV`)의 적만 |
| 바닥 아이템 전체 목록·수 | 어디에 뭐가 있는지 다 보임 | `Level.heaps` | 시야 안 또는 본 적 있는 아이템만 |
| 계단 위치 | 탐색 없이 바로 직행 가능 | `Level.exit`, `transitions` | 발견한 계단만 |
| 숨겨진 문 | 찾아야 보이는 통로가 드러남 | `Terrain.SECRET_DOOR` | 발견 전엔 벽으로 표시 |
| 숨겨진 함정 | 밟기 전 위험을 미리 앎 | `Terrain.SECRET_TRAP`, `Trap.visible` | 발견 전엔 바닥으로 표시 |
| 미감정 물약·주문서·반지의 진짜 정체 ⭐ | 불확실한 정보가 사라짐 | `isKnown()`, 아이템 클래스 이름 | "주황색 물약"처럼 겉모습만 |
| 장비의 저주 여부 | 착용 전 위험을 미리 앎 | `Item.cursed`, `cursedKnown` | 확인 전엔 "저주 여부 모름" |
| 장비의 강화 수치 | 성능을 미리 앎 | `Item.levelKnown`, `buffedLvl()` | 확인 전엔 "수치 모름" |
| 상자로 위장한 미믹 | 함정 몬스터가 드러남 | `Mimic`, `GoldenMimic` 등 | 정체 드러나기 전엔 상자로 |
| 몬스터 드롭 아이템 | 잡으면 뭘 주는지 미리 앎 | `Mob.loot`, `lootChance()` | 넘기지 않음 |
| 맵 생성 시드 | 다음 층을 예측할 여지 | `Dungeon.seed` | 넘기지 않음 (실험 기록용으로만) |

> ⚠️ **가장 흔한 실수**: 미감정 물약도 내부적으로는 `PotionOfHealing` 같은 진짜 이름의 클래스예요. 아이템 이름을 뽑을 때 클래스 이름을 쓰면 AI가 정답을 알게 됩니다. 반드시 **게임 화면에 표시되는 이름**을 쓸 것.

**원칙**: 플레이어 화면에 보이는 것만 AI에게 보여준다.
